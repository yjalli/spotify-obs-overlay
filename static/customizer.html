How to Add to OBS Studio in 30 Seconds

  1. In OBS Studio, click + under Sources and select Browser.
  2. Name it Spotify Overlay and paste the local URL:
    http://localhost:8888/overlay
  3. Set Width to 1920 and Height to 1080.
  4. Leave Custom CSS blank (it is already 100% transparent), and click OK!
